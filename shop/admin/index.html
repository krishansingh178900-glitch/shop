Supabase Credentials & Setup

Configure your Supabase project credentials. Credentials are saved locally in browser storage and used for authentication, database records, and storage uploads.

Found in your Supabase Dashboard under Project Settings > API > Project URL.
Use the anon public key. NEVER use the service_role secret key in browser code!
✦ Setup Steps in Supabase: 1. Open your Supabase SQL Editor and execute the script in supabase/schema.sql.
2. In Authentication > Users, click Add User > Create User to create your administrator email & password.
3. Click "Test Live Connection" below to verify everything is wired up!
